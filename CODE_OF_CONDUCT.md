# Code of conduct

We want participation in BrowserCortex to be safe, respectful, and constructive.

Be considerate, discuss technical decisions in good faith, respect privacy, and focus criticism on behavior and code rather than people. Harassment, threats, discriminatory language, doxxing, deliberate exposure of secrets, and sexualized or abusive conduct are not acceptable in project spaces.

Maintainers may edit or remove contributions and restrict participation when behavior threatens people, the project, or user data. For a conduct concern, use a private contact method listed on a maintainer's GitHub profile. If no private project contact is available, use GitHub's report-abuse flow. Do not place sensitive conduct details or unrelated personal data in a public issue.

This policy applies to repository discussions, reviews, and other spaces where someone represents the project.
