# Research track

This directory contains non-production experiments for the research areas listed below and in the [public roadmap](../docs/roadmap.md). Nothing here can grant a capability, execute a privileged action, enable online processing, or expand passive capture. Results must be measured on held-out synthetic data before adoption.

| Area | Status |
| --- | --- |
| Compact route classifier comparison | Prototype harness |
| Planner distillation data | Generator sketch only |
| WebMCP compatibility | Version-neutral translation prototype |
| Vision and audio | Design study only |
| Offscreen extension runtime | Feasibility study only |
| Additional browser support | Unmeasured matrix |
| Bounded local suggestions | Pure read-only prototype |
| Additional site integrations | Review template only |
