# Support

BrowserCortex is an open-source beta maintained on a best-effort basis. There is no paid support plan or guaranteed response time.

## Where to ask

| Need | Use |
| --- | --- |
| Setup, usage, architecture, or design question | [GitHub Discussions](https://github.com/Zen-ctrl/browser-cortex/discussions) |
| Reproducible bug with synthetic data | [Bug report](https://github.com/Zen-ctrl/browser-cortex/issues/new?template=bug.md) |
| Browser, model, or hardware compatibility result | [Compatibility issue templates](https://github.com/Zen-ctrl/browser-cortex/issues/new/choose) |
| Feature proposal | [Feature request](https://github.com/Zen-ctrl/browser-cortex/issues/new?template=feature.md) |
| Documentation problem | [Documentation issue](https://github.com/Zen-ctrl/browser-cortex/issues/new?template=documentation.md) |
| Security vulnerability | [Private security advisory](https://github.com/Zen-ctrl/browser-cortex/security/advisories/new) |

Before posting, remove credentials, personal documents, private prompts, real browser profiles, absolute home paths, machine names, account identifiers, and unsanitized diagnostic exports. Prefer the synthetic demo and reserved `example.test` values.

Include the smallest reproduction, the exact BrowserCortex commit, commands actually run, browser and operating-system family when relevant, expected behavior, actual behavior, and whether data may have left the device or an external action has an unknown outcome.

See [Troubleshooting](docs/troubleshooting.md) before opening a setup issue.
