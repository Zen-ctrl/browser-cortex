# Changelog

All notable changes to BrowserCortex are recorded here. Features remain experimental until the final evidence report confirms them.

## 0.3.0-beta.1 - 2026-09-22

### Added

- Strict TypeScript workspace for SDK, workbench, extension, examples, and runtime adapters.
- Default-deny capabilities, exact approval binding, redaction, disclosure, and route receipts.
- Encrypted local vault, source-backed retrieval, bounded deterministic workflows, and synthetic fixtures.
- Lazy real-model adapters for Transformers.js embeddings and WebLLM generation.
- Manifest V3 extension and local-first React workbench.
- Optional authenticated developer gateway, packaging, hygiene, and release verification scripts.
- Transactional encrypted vault migration from schema v1 to v2 with retained-ciphertext rollback and restart recovery.
- Source-supported structured generation, exact workflow previews, cancellable imports, worker-failure recovery, and trusted real-model evidence binding.

### Changed

- Reorganized documentation around beginner setup, technical architecture, package ownership, troubleshooting, and project history.
- Added public collaboration guidance, support routing, repository privacy checks, and public-safe release evidence rules.
- Removed stale private-publication scripts and internal implementation notes from the public source tree.
- Reduced diagnostic output to portable capability checks instead of account, path, disk, or exact host details.

### Limitations

- Browser, hardware, real-model, offline, and extension support claims remain limited to recorded final test evidence.
- No npm publication, browser-store submission, public hosted gateway, or mandatory account service is included.
